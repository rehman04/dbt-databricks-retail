# dbt-databricks-retail

A production-quality **dbt** project modeling a retail/e-commerce dataset on **Databricks**, using **Unity Catalog** and the **medallion architecture** (bronze → silver → gold).

> 🚧 Under active build. This README will be expanded with architecture diagrams, DAG screenshots, and full setup instructions as the project is built out.

## Stack

- [dbt-core](https://github.com/dbt-labs/dbt-core) + [dbt-databricks](https://github.com/databricks/dbt-databricks)
- Databricks Unity Catalog (Delta Lake)
- GitHub Actions (CI, planned)
